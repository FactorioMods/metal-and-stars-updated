# Metal and Stars: Updated

Retains the current Metal and Stars worlds and production systems with Factorio 2.1 APIs and matching maintained graphics and common-prototype dependencies. Legacy direct routes and legacy generated recipe names are available through separate compatibility addons.

Requires Factorio 2.1.24 or later. Enable the dependencies listed in the mod manager. This fork keeps the original mod’s content rather than introducing a new balance model.

Existing saves using metal-and-stars can migrate to this mod identity. Keep a backup when changing a mod set, and disable the original when selecting this fork.

Original mod: [ metal-and-stars ](https://mods.factorio.com/mod/metal-and-stars). Original author credits and applicable license notices are retained in the source package.
